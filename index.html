Ember2D Scripting API Reference

Version 0.4.9 — Scripts are Rhai files attached to entities. Each script may define on_start(id, ctx), on_update(id, ctx), and on_collide(id, other_id, ctx).

Basics

log(message)

Prints a string to the in-engine console and terminal.

get_delta()→ float

Seconds since the last frame (real-time mode) or 1.0 (turn-based mode).

get_elapsed()→ float

Total seconds since the level started.

load_level(path)

Queues a level transition. path is relative to the project folder. Transition happens at end of frame.

trigger_turn() V0.4.8

In Turn-Based games, signals that a simulation step should occur this frame.

spawn(glyph, x, y, tag)→ int (id)

Spawns a new 1×1 trigger-collider entity and returns its ID. glyph is a single character string.

despawn(id)

Removes an entity from the world at end of frame.

Transform & Physics

get_x(id)→ float  /  get_y(id)→ float

Returns the entity's current world position on each axis.

get_position(id)→ [x, y] V0.4.9

Returns world position as a two-element array.

set_position(id, x, y)

Teleports an entity to the given world coordinates.

get_vel_x(id)→ float  /  get_vel_y(id)→ float

Returns the entity's current velocity on each axis.

get_velocity(id)→ [vx, vy] V0.4.9

Returns velocity as a two-element array.

set_velocity(id, vx, vy)

Sets velocity. Applied during the physics integration step each frame.

get_distance(id_a, id_b)→ float

Returns the Euclidean distance between two entities' positions.

get_angle_to(from_id, to_id)→ float (radians)

Returns the angle in radians from one entity toward another. Use cos()/sin() to get a direction vector.

Visuals & Sprites

get_glyph(id)→ string V0.4.9

Returns the entity's current ASCII character as a one-character string.

set_glyph(id, char)

Changes the entity's ASCII glyph. Pass a one-character string.

get_color(id)→ [fg, bg] V0.4.9

Returns the entity's foreground and background color names as strings.

set_color(id, fg, bg)

Sets the foreground and background color. Use color name strings (see Reference).

get_texture(id)→ string V0.4.9

Returns the entity's current texture path, or empty string if none.

set_texture(id, path) V0.4.7

Assigns an image texture for 2D sprite mode. Pass an empty string to clear it and revert to glyph rendering.

set_animation(id, frames, rate)

Sets an ASCII animation. frames is a string of characters (e.g. "~-~"), rate is frames per second.

is_visible(id)→ bool  /  set_visible(id, bool)

Gets or sets whether an entity is rendered. Invisible entities still receive script updates.

get_z_order(id)→ int  /  set_z_order(id, z)

Gets or sets the rendering sort order. Higher values render on top. Default is 0.

Tags & Entities

get_tag(id)→ string

Returns the entity's tag string, or empty string if none.

set_tag(id, tag) V0.4.9

Assigns or changes the entity's tag.

has_tag(id, name)→ bool

Returns true if the entity's tag equals name.

find_by_tag(tag)→ int (id)

Returns the ID of the first entity with a matching tag, or -1 if not found.

find_all_by_tag(tag)→ [id, ...]

Returns an array of IDs for all entities with a matching tag.

count_by_tag(tag)→ int

Returns the number of live entities with a matching tag.

entity_exists(id)→ bool

Returns true if the entity with the given ID is still alive.

get_spawn_point(name)→ [x, y]

Returns the world position of a named spawn marker placed in the editor, or an empty array if not found.

Input

is_held(key)→ bool

Returns true while the key is held down. Key is a string (see Reference).

just_pressed(key)→ bool

Returns true only on the first frame the key is pressed.

get_mouse_x()→ float  /  get_mouse_y()→ float

Mouse position in screen cell coordinates (not world coordinates).

get_mouse_world_x()→ float  /  get_mouse_world_y()→ float

Mouse position translated into world coordinates (camera offset applied).

mouse_left_pressed()→ bool  /  mouse_right_pressed()→ bool

Returns true only on the first frame the mouse button is clicked.

mouse_left_held()→ bool  /  mouse_right_held()→ bool

Returns true while the mouse button is held down.

Spatial Queries

get_entity_at(x, y)→ int (id)

Returns the ID of an entity whose collider contains the given world point, or -1.

is_solid_at(x, y)→ bool

Returns true if any solid-flagged collider occupies the given world point.

find_entities_in_rect(x, y, w, h)→ [id, ...]

Returns IDs of all entities whose colliders intersect the given rectangle.

raycast(x1, y1, x2, y2, mask)→ [id, hit_x, hit_y] V0.4.5

Casts a line segment and returns the first solid hit as [id, hit_x, hit_y], or an empty array if nothing was hit. mask is an array of layer names to include; pass [] to hit all solid entities.

get_path(x1, y1, x2, y2, mask)→ [[x,y], ...] V0.4.5

A* pathfinding on the integer grid. Returns an ordered array of [x, y] steps from start to target. mask is an array of layer names that act as obstacles; pass [] to treat all solids as obstacles. Returns empty array if no path exists (max 2000 iterations).

Colliders

get_collider_w(id)→ float  /  get_collider_h(id)→ float

Returns the width or height of the entity's collider in world units.

set_collider_size(id, w, h) V0.4.9

Resizes the entity's collider.

is_collider_solid(id)→ bool

Returns true if the entity's collider blocks movement and raycasts.

set_collider_solid(id, bool) V0.4.9

Sets whether the collider is solid. Non-solid (trigger) colliders still fire on_collide.

get_collider_layer(id)→ string  /  set_collider_layer(id, layer)

Gets or sets the collision layer name. Used to filter raycasts and pathfinding.

get_collider_mask(id)→ [string, ...]  /  set_collider_mask(id, mask)

Gets or sets which layers this entity interacts with. mask is an array of layer name strings.

Camera & Viewport

get_camera_x()→ float  /  get_camera_y()→ float

Returns the current camera position in world coordinates.

set_camera(x, y)

Moves the camera to the given world position. Commonly called each frame targeting the player.

shake_camera(intensity, duration)

Applies a screen-shake effect. intensity is the displacement amount, duration is in seconds.

get_viewport_width()→ int  /  get_viewport_height()→ int

Returns the viewport size in character cells. Useful for centering HUD elements.

Randomness

random_int(min, max)→ int

Returns a random integer in the inclusive range [min, max].

random_float()→ float

Returns a random float in [0.0, 1.0).

random_bool(chance)→ bool

Returns true with probability chance (0.0 = never, 1.0 = always).

random_choice(array)→ dynamic

Returns a random element from an array. Returns unit if the array is empty.

Timers

start_timer(name, duration)

Starts a named countdown timer for the current entity. duration is in seconds. Calling again resets it.

timer_done(name)→ bool

Returns true exactly once when the named timer reaches zero, then consumes it.

cancel_timer(name)

Cancels a running timer before it fires.

Globals & Persistence

Globals are shared between all scripts within a level and reset on level load. Persistent values survive level transitions.

set_global(key, val)  /  get_global(key)→ dynamic

Stores or retrieves a value shared across all scripts in the current level.

has_global(key)→ bool

Returns true if the global key exists.

remove_global(key)

Deletes a global key.

set_persistent(key, val)  /  get_persistent(key)→ dynamic

Stores or retrieves a value that survives level transitions (e.g. score, inventory).

has_persistent(key)→ bool

Returns true if the persistent key exists.

clear_persistent(key)

Deletes one persistent key.

clear_all_persistent()

Deletes all persistent data.

HUD Drawing

HUD calls draw to the UI layer fixed to the screen (not the world). Coordinates are in screen cells, origin top-left.

draw_hud(x, y, text, fg, bg)

Draws a string at screen position (x, y).

draw_box(x, y, w, h, fg, bg)

Draws a border-only box using box-drawing characters.

fill_rect(x, y, w, h, char, fg, bg)

Fills a rectangular region with a repeated character.

draw_menu(x, y, w, options, selected, fg, bg, sel_fg, sel_bg)

Draws a vertical menu list. options is a string array, selected is the highlighted index. Highlighted item uses sel_fg/sel_bg.

draw_panel(x, y, w, h, title, fg, bg)

Draws a bordered panel with a title in the top border.

clear_hud()

Clears all HUD draws from the previous frame. Useful to avoid overdraw when rebuilding the HUD each frame.

Audio

play_sound(path)

Plays a sound effect at full volume. Path is relative to the project folder (.ogg or .mp3).

play_sound_at(path, x, y) V0.4.4

Plays a sound with volume attenuated by distance from the camera position. Useful for world-space effects.

play_music(path)

Starts looping background music, stopping any currently playing track.

stop_music()

Stops the currently playing music track.

Particles

emit_particles(x, y, glyph, fg)

Emits a burst of ASCII particles at world position (x, y). glyph is a single character, fg is a color name string.
