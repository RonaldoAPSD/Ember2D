Ember2D Rhai Scripting API

Scripts in Ember2D are plain text files with a .rhai extension. Each script defines callback functions that the engine executes at specific moments.

All interactions with the game world happen through the ctx (Context) object passed into your functions. The engine preserves the scope of your scripts between frames, meaning any let variables you define will persist.

Hot-Reloading: During play mode, saving changes to a .rhai file will automatically recompile and apply the script in real-time!

Callbacks

Implement these functions in your script files to hook into the engine.

fn on_start(entity_id, ctx)

Called exactly once when the level finishes loading and the entity is spawned into the world.

fn on_update(entity_id, ctx)

Called every single frame before physics are applied. Put your AI logic, input handling, and movement here.

fn on_collide(entity_id, other_id, ctx)

Called when this entity's bounding box overlaps with another entity's bounding box.

Read: Position & Velocity

Retrieve the physical state of any entity by its ID.

ctx.get_x(id) → f64

Returns the X position of the entity.

ctx.get_y(id) → f64

Returns the Y position of the entity.

ctx.get_vel_x(id) → f64

Returns the X velocity of the entity.

ctx.get_vel_y(id) → f64

Returns the Y velocity of the entity.

Read: Tags

Search for entities using semantic string tags.

ctx.get_tag(id) → String

Returns the tag of the entity, or an empty string if none.

ctx.has_tag(id, name) → bool

Returns true if the entity has the specified tag.

ctx.find_by_tag(name) → i64

Returns the ID of the first entity found with this tag. Returns -1 if no entity matches.

ctx.find_all_by_tag(name) → Array

Returns an array containing the IDs of all currently alive entities with this tag.

Read: Input

Check keyboard state. Valid key strings include: w, a, s, d, e, q, r, f, z, x, c, v, up, down, left, right, space, enter, escape, shift, ctrl, tab, 0-9.

ctx.is_held(key_name) → bool

Returns true continuously while the specified key is held down.

ctx.just_pressed(key_name) → bool

Returns true only on the exact frame the key was initially pressed.

Read: Time

ctx.get_delta() → f64

Returns the time elapsed since the last frame in seconds. Essential for smooth, framerate-independent movement or timers.

ctx.get_elapsed() → f64

Returns the total time elapsed in seconds since the level was loaded.

Read: Spawn Points

ctx.get_spawn_point(name) → Array

Returns an array [x, y] of the coordinates for a named spawn point placed in the level editor. Returns an empty array [] if not found.

Write: Motion & Appearance

Note: All write commands are deferred. They are queued up and applied safely at the end of the frame after all scripts have finished running.

ctx.set_velocity(id, vx, vy) → ()

Sets the velocity of the entity. Physics will automatically apply this to the position next frame.

ctx.set_position(id, x, y) → ()

Instantly teleports the entity to the given coordinates.

ctx.set_glyph(id, glyph_string) → ()

Changes the ASCII character displayed for this entity. Only takes the first character of the string.

ctx.set_color(id, fg_color, bg_color) → ()

Changes the colors of the entity. Valid strings: Black, White, Red, Green, Yellow, Cyan, DarkBlue, DarkGrey, DarkGreen, Grey, Reset.

Write: Entity Lifecycle

ctx.despawn(id) → ()

Removes the entity from the world at the end of the current frame.

ctx.spawn(glyph, x, y, tag) → i64

Creates a new entity in the world and returns its ID. The ID is valid immediately, so you can call set_velocity on it in the same frame.

Write: Game Flow & HUD

ctx.load_level(path) → ()

Transitions the game to the specified .level file at the end of the frame.

ctx.log(message) → ()

Prints a message to the Level Editor's Console panel. Highly useful for debugging.

ctx.draw_hud(x, y, text, fg, bg) → ()

Draws text onto the screen for a single frame. It renders on top of all sprites.

Write: Audio

ctx.play_sound(path) → ()

Plays a sound effect file (e.g. "hit.ogg") once. Fire-and-forget.

ctx.play_music(path) → ()

Starts looping a music track. Will automatically stop any currently playing music.

ctx.stop_music() → ()

Stops the currently playing music track.
