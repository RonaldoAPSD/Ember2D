Ember2D Documentation

Ember2D is a character-cell based game engine. It uses Rhai for scripting, allowing you to build complex logic with a simple, Rust-like syntax.

Tutorial: Your First Game

Let's build a simple chaser game where the player avoids a goblin.

Step 1: Create the Player

In the editor, place an entity and set its script to player.rhai. Give it the tag player.

// player.rhai
fn on_update(id, ctx) {
    let speed = 10.0;
    let vx = 0.0;
    let vy = 0.0;

    if ctx.is_held("w") { vy = -speed; }
    if ctx.is_held("s") { vy = speed; }
    if ctx.is_held("a") { vx = -speed; }
    if ctx.is_held("d") { vx = speed; }

    ctx.set_velocity(id, vx, vy);
}

Step 2: Create the Enemy

Place another entity with the script chaser.rhai and the character G.

// chaser.rhai
fn on_update(id, ctx) {
    let player = ctx.find_by_tag("player");
    if player < 0 { return; }

    let dist = ctx.get_distance(id, player);
    if dist < 10.0 {
        let angle = ctx.get_angle_to(id, player);
        let speed = 4.0;
        ctx.set_velocity(id, cos(angle) * speed, sin(angle) * speed);
    } else {
        ctx.set_velocity(id, 0.0, 0.0);
    }
}

fn on_collide(id, other, ctx) {
    if ctx.has_tag(other, "player") {
        ctx.play_sound("hurt.ogg");
        ctx.shake_camera(5.0, 0.3);
        ctx.log("You were caught!");
    }
}

Callbacks

fn on_start(entity_id, ctx)

Called once when the entity is spawned or the level starts.

fn on_update(entity_id, ctx)

Called every frame. Main logic goes here.

fn on_collide(entity_id, other_id, ctx)

Called when two entities with colliders overlap.

Read: Position & Velocity

ctx.get_x(id) → f64
ctx.get_y(id) → f64

Returns the current position of the entity.

ctx.get_vel_x(id) → f64
ctx.get_vel_y(id) → f64

Returns the current velocity of the entity.

Read: Tags & Search

ctx.get_tag(id) → String

Returns the semantic tag assigned to this entity.

ctx.find_by_tag(tag) → i64

Finds the first entity with the given tag. Returns -1 if not found.

ctx.find_all_by_tag(tag) → Array

Returns an array of IDs for all entities with the tag.

ctx.count_by_tag(tag) → i64

Returns how many entities currently have this tag.

Read: Keyboard & Mouse

ctx.is_held(key) → bool
ctx.just_pressed(key) → bool

Check keyboard state. Keys: "w", "a", "s", "d", "up", "space", etc.

ctx.get_mouse_x() → f64
ctx.get_mouse_y() → f64

Returns mouse coordinates relative to the screen (viewport).

ctx.get_mouse_world_x() → f64
ctx.get_mouse_world_y() → f64

Returns mouse coordinates relative to the world (accounting for camera).

ctx.mouse_left_pressed() → bool
ctx.mouse_left_held() → bool

Check mouse button state.

Read: Spatial Queries

ctx.get_entity_at(x, y) → i64

Returns the ID of the entity at the given world coordinates, or -1.

ctx.is_solid_at(x, y) → bool

Returns true if there is a solid collider at the coordinates.

ctx.find_entities_in_rect(x, y, w, h) → Array

Returns IDs of all entities intersecting the specified rectangle.

ctx.get_distance(id1, id2) → f64

Returns the Euclidean distance between two entities.

ctx.get_angle_to(id1, id2) → f64

Returns the angle in radians from id1 to id2.

Write: Motion & Appearance

ctx.set_velocity(id, vx, vy)

Sets movement for the next frame.

ctx.set_position(id, x, y)

Instantly teleports the entity.

ctx.set_glyph(id, "char")

Changes the entity's ASCII character.

ctx.set_color(id, fg, bg)

Sets the character and background color (e.g., "Red", "Black").

ctx.set_visible(id, bool)

Hides or shows an entity.

ctx.set_z_order(id, z)

Sets render order (higher Z draws on top). Default is 2.

Write: State & Persistence

ctx.set_global(key, value)
ctx.get_global(key) → Dynamic

Store values shared between all scripts in the current level.

ctx.set_persistent(key, value)
ctx.get_persistent(key) → Dynamic

Store values that persist even when changing levels (e.g., player health, inventory).

Write: Entity Lifecycle

ctx.spawn("char", x, y, tag) → i64

Creates a new entity and returns its ID.

ctx.despawn(id)

Removes the entity from the world.

Write: Game Flow & HUD

ctx.load_level("path/to.level")

Switches to a new level at the end of the frame.

ctx.log("message")

Prints a message to the editor console.

ctx.draw_hud(x, y, "text", fg, bg)

Draws text at screen-space coordinates.

ctx.draw_box(x, y, w, h, fg, bg)

Draws an outlined box in screen-space.

ctx.fill_rect(x, y, w, h, "char", fg, bg)

Fills a rectangle in screen-space.

ctx.clear_hud()

Removes all HUD elements drawn this frame.

Write: Camera & FX

ctx.set_camera(x, y)

Focuses the camera on specific world coordinates.

ctx.shake_camera(intensity, duration)

Applies a screenshake effect.

Utilities: Randomness

ctx.random_int(min, max) → i64

Returns a random integer between min and max (inclusive).

ctx.random_float() → f64

Returns a random float between 0.0 and 1.0.

ctx.random_bool(chance) → bool

Returns true based on the given probability (0.0 to 1.0).

ctx.random_choice(Array) → Dynamic

Returns a random element from the provided array.

Utilities: Timers

ctx.start_timer(name, seconds)

Starts a named timer for this entity.

ctx.timer_done(name) → bool

Returns true once the timer reaches zero, then resets.
