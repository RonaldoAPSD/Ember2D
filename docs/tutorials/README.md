# Ember2D tutorials

Build-along guides. Each starts from an empty project made with the New
Project wizard and ends with a working game. Everything is done in the
editor; there's no Rust to write and no file to edit by hand.

Do them in this order. Each one assumes what the earlier ones showed.

| # | Tutorial | You build | You learn |
|---|---|---|---|
| 1 | [Your first project](first-project.md) | **Coin Grab**: a room, five coins, a HUD | the wizard, the editor's panels, the palette, painting and layers, a first script, playing and exporting |
| 2 | [Ember Assault](shooter.md) | a real-time arena shooter, and a stress test with 300+ entities | spawning from scripts, collision layers and masks, waves, enemy shots, a boss made of parented parts, sound, a saved high score, a custom pause menu |
| 3 | [Depths of Ember](roguelike.md) | a 20-floor turn-based roguelike | turn-based scripts (`on_input`/`on_turn`), floors generated by a script, the seeded random stream, fog of war, monsters' turns, items, menus, aiming, levelling, save and Continue |
| 4 | [Emberfall](rpg.md) | a small RPG with Kenney's pixel art | square world cells, importing tilesets, animation clips, y-sorting, scenes (title, pause, battle), dialogue and menus, nested persistent data, saving mid-game |

The finished games ship in `demos/`. Run one beside its tutorial to
compare:

```
cargo run -- demos/shooter/arena.level
cargo run -- demos/roguelike/title.level
cargo run -- demos/rpg/title.level
```

## Conventions

- **Bold** names a menu item, a key or a button: **File > New Script**,
  **F5**, **[ Edit ]**.
- Script listings are complete files unless the text says it shows only
  part of one. The shipped demo scripts are commented throughout.
- Paths are relative to your project folder (`Projects/<Name>/` by
  default).
- Run `cargo run` from the repository root.
